# PR（1RM）估算工作流

**触发**：用户想估算 1RM 但不需要完整计划（"帮我估一下XX的PR"）。

**执行**：读取 `references/intensity/pr-estimation.md` → 收集训练经验/性别/体重 → 选择估算方法 → 输出保守值+范围。

> 估算结果仅作为起点，实际训练中 2-3 周通过 RPE 校准。
