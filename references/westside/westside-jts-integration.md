# Westside → JTS 方法论整合脉络

**来源**: The Westside Barbell Book of Methods (Louie Simmons, 2023)
**定位**: Westside 是 JTS 方法论的重要源头之一。JTS 保留其核心框架，加入 MEV/MRV、RPE 自我调节和个体差异系统，使其更适合自然训练者。
**配套文件**: 核心量化标准 `book-of-methods-core.md` · 特殊力量分类学 `special-strengths.md` · GPP/恢复 `gpp-recovery.md`

---

## 1. 整体关系：Westside 是"原型"，JTS 是"进化版"

| 维度 | Westside (原著) | JTS 继承了什么 | JTS 改良了什么 |
|------|----------------|---------------|---------------|
| **周期化类型** | 并发周期化（conjugated periodization，多种方法同时使用） | ✅ 保留：同周发展多种素质 | ➕ 加入容量期→减载→力量期→冲刺期的**阶段划分** |
| **强度控制** | 基于经验的百分比（按水平反向设定） | ✅ 保留：百分比区间作为参考 | ➕ 加入 **RPE 自我调节**，尊重日内波动 |
| **容量管理** | 高工作量靠**更多课次**（额外课系统）而非更大强度 | ✅ 保留：GPP/额外课思路 | ➕ 用 **MEV/MRV 系统**量化个体容量边界 |
| **动作轮换** | **标准 1-2 周一换**（4-5 变式每两周轮换一个；每周轮换仅高水平） | ✅ 保留：变式多样化 | ➕ 轮换周期延长（4-6周），便于追踪进度 |
| **疲劳管理** | 动作轮换 + >90% 课内次数上限 + GPP | ✅ 保留：GPP 主动恢复、90%+ 不超 3 周规则 | ➕ 加入 **减载周、疲劳上限审计** |
| **个体差异** | 百分比数学系统（300 与 900 磅深蹲者同表） | ❌ 不采用 | ➕ 9因素个体差异系统（性别/体重/经验等） |

**结论**: JTS = Westside 框架 × MEV/MRV 安全边界 × RPE 自我调节。Westside 是"怎么练"，JTS 补充了"练多少"和"什么时候停"。

## 2. Zatsiorsky 三大方法 → JTS 的应用

Westside 基于 Zatsiorsky (1995) 的三大方法（量化处方详见 `book-of-methods-core.md` §2）：

| 方法 | Westside 应用 | JTS 保留/改良 |
|------|-------------|-------------|
| **Maximal Effort** (最大努力法) | 每周 1 次下肢 + 1 次卧推；90-100%+；1-3 次反复；**课内 >90% 最多 2-3 次**；每个变式 1-2 周 | ✅ 保留为 **TS (Top Set)**，但限于力量期/冲刺期（W5-8），容量期不做；上限 RPE 8.5 |
| **Dynamic Method** (动态法) | 次最大重量×最大速度+补偿性加速；**百分比按水平反向**：高水平 40-50% / 新手 50-60%；卧推 DE 固定重量不波浪 | ✅ 保留为 **速度训练**，但不再强制每周固定日。JTS/RTS 将动态法演化为 70-80% 1RM（尽速加速，RPE 7-8） |
| **Repetition Method** (重复法) | 只用于专项动作、从不在三大项上力竭；**时间制**（3-4 分钟组）；恢复档 ≤30% | ✅ 保留用于辅助动作，但加入**双进阶**（先加次数再加重），避免力竭；时间制见 `gpp-recovery.md` |

## 3. 动作分类系统：Westside 核心，JTS 全部保留

这是 JTS 从 Westside 继承的最完整框架。原著每日结构为 **4 层**：

```
Westside 每日结构：

  1| Main Exercise (主项)
  │ 比赛动作或直接变式（ME/DE 形式）
  │ 例: Box Squat, Board Press, Rack Pull
  2| Supplemental Exercise (补充)
  │ 按弱点分析选择
  │ 例: Close-grip Bench, Good Morning
  3| Accessory Exercise (辅助)
  │ 肌群建设 + 预防损伤（腹/下背 3-4×8-15）
  │ 例: Triceps Pushdown, Face Pull, Reverse Hyper
  4| Other (其他)
       预康复、加容量、促进恢复（握力/颈/背阔）
```

**关键差异**：
- Westside: 主项变式 **1-2 周一换**（标准处方：4-5 个变式每两周轮换一个 → 10 周大周期；每周轮换仅高水平选手）
- JTS: 主项 **每 4-6 周更换**（减少适应，便于追踪进度）

## 4. 波浪形加载 → JTS 的阶段化周期

### Westside 的波浪（三周钟摆波）

Westside 使用「三周钟摆波」进行动态日的速度训练——核心逻辑是"三周后人体无法继续变快或变强，必须退回重来"：

```
深蹲动态日（钟摆波示例）：
W1: 50% 1RM —— 速度训练
W2: 55% —— 持续增速
W3: 60% —— 负荷顶点
W4: 回到 50% 开始新周期
```

原著补全的量化细节（`book-of-methods-core.md` §4）：**平装载荷**（波内总吨位恒定，单日 DE 吨位 ≈ 目标成绩×12）、**60% 法则**（ME 吨位 ≈ DE 的 60%）、波时长矩阵（力量-速度波 ≤2 周、circa-max 3 周）、延迟转化减载 4 周（高手 2 周）。

> 💡 注意：Jim Wendler 后来在此基础上独立创造了 **5/3/1 程序**，两者同源但实现路径不同。5/3/1 是 Westside 思想的衍生发展，不是 Westside 原著内容。

### JTS 的阶段化保留

| JTS 阶段 | 对应的 Westside 波浪元素 |
|----------|----------------------|
| 容量积累期 W1-3 (5×8 @ RPE 6-7) | ≈ 钟摆波的"容量"期（对应肌肥大需求） |
| 减载期 W4 (降容 40-50%) | JTS **新增**，Westside 依赖轮换与额外课管理疲劳 |
| 力量建立期 W5-6 (TS + BO) | ≈ Max Effort Day 的变体（保留强度但控制疲劳） |
| 冲刺期 W7-8 (TS 继续递增) | ≈ 钟摆波顶点附近的高强度期 |

**JTS 的改良**：将 Westside 的 3 周钟摆波周期扩展为 8 周中周期，用**减载周**取代 Westside 依赖**动作轮换**作为疲劳管理手段。

## 5. 特殊力量素质 → JTS 的薄弱环节分析

Westside 特殊力量并非只有"4 种"： 是五挡变速箱（quickness → absolute）， 是 **8+ 维分类学**（最大力量/力量耐力/力量-速度/速度力量/爆发力/加速力量/向心/离心/等长）。

完整分类学、月度次数配额（80 次/月速度力量 + 16 次/月力量-速度）、两周退化规则、mini-max 粘滞点理论：见 `special-strengths.md`。

**JTS 的效率优势**：Westside 通过**并发轮换大量动作**被动覆盖所有素质；JTS 通过**分析用户具体短板**定向选择素质与动作，样本量小、效率更高。

## 6. 可变阻力（弹力带/铁链）——备注级，默认不引入

**核心原理**（Westside 和 JTS 一致）：弹力带/铁链在底部阻力最小、顶部最大，匹配人体自然力量曲线。

**量化细则**（65/35 带杠比、链分级表、四阶段带周期）：见 `book-of-methods-core.md` §6。设备不常备时设计计划默认不引入，用动作变式（暂停/deficit/变杠）达到同类效果；有设备时按 §6 量化使用。

## 7. GPP 与恢复

**Westside 的核心逻辑**（JTS 完全保留，量化见 `gpp-recovery.md`）：
- GPP 不是"辅助训练"，而是**恢复手段**——原著明确为自然训练者辩护
- **额外课系统**：15-30 分钟、2-10 次/周、大肌群 72h/小肌群 24h
- **雪橇**（场地条件依赖，按需选用）：60% 规则、向后拖解压脊柱
- 重复法恢复档 ≤30% 作主动恢复

**JTS 补充**：GPP 安排在**休息日**或**训练日之后**，不占用主项训练时间。

## 8. 为什么 JTS 更适合自然训练者

| Westside 的局限 | JTS 的解决 |
|----------------|-----------|
| 每周 max out 的恢复假设（装备+药物语境） | TS 只出现在 W5-8，且上限 RPE 8.5 |
| 高工作量辅助训练（恢复不及） | MRV 审计确保不超个体恢复边界 |
| 依赖经验（百分比数学系统无个体化） | 9 因素个体差异系统 + RPE 自我调节 |
| 无明确的减载机制 | 每 4 周一次减载周（W4, W8…） |
| 主项 1-2 周一换（追踪困难） | 主项每 4-6 周更换，便于追踪进度 |

**Westside 仍需保留的部分**：
- 90%+ 不超 3 周规则与课内 >90% 次数上限（CNS 保护的操作化）
- 弱点变式轮换思路（连结训练：效力下降就换下一个）
- 硬拉"别硬拉"原则（6/10 早安式 ME 日分布）——与硬拉容量原则互证
- 额外课系统（自然训练者增量工作量的正解）
