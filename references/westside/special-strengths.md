# Westside 特殊力量分类学

**来源**: The Westside Barbell Book of Methods (Louie Simmons, 2007) Ch2（五挡变速箱）+ Ch4（完整分类学）
**定位**: 弱点分析的"素质层"——先定位是哪种力量素质卡住，再选动作（动作层见 `../exercises/weak-points.md` 与 `assistance-exercise-database.md`）。

---

## 1. 分类学总表（Ch4）

| 素质 | 定义/表现 | 训练法 | 关键量化 |
|---|---|---|---|
| **最大力量** | 一切素质的地基（"没人能用 400 做 10-12 次如果他的单次只有 420"） | ME 法 | 90-100%+ |
| **力量耐力** | 静态/动态两型 | 重复法 | %按项目 30-80%；9-12 组/课；**最多连续用 2 周** |
| **力量-速度（strength-speed）** | 移动大重量尽可能快 | ME 法变式 | **~16 次/月** 配额 |
| **速度力量（speed-strength）** | 轻重量最大速度 | DE 法 | 40-60%；**~80 次/月**（含爆发力）配额 |
| **爆发力（explosive strength）** | 牵张-收缩后瞬间最大力 | 冲击法（shock training）：悬垂翻、深跳、箱蹲±带/链 | plyo 门槛：深蹲 ≥2× 体重 |
| **加速力量** | 延长最大力输出时间 | 带/链匹配力量曲线（备注级，设备不常备） | 带 35-40% 封顶 |
| **向心/起始力量** | 从静息克服惯性，**无牵张反射辅助**——硬拉核心素质 | 架上起杠、链悬早安式、暂停变式 | 硬拉无离心阶段 → 以此为主 |
| **离心力量** | 离心是伤痛高发相位；纯离心训练有失败案例 | 控制下降即可，不做超量离心 | **下降只用 ≤50% 离心力量**；速度工作离心 0.7-0.8 m/s ≈ 向心同速最优（Tendo 实测） |
| **等长/准等长** | 关键角度的力量输出 | Hoffman 法（75% 负荷推入定位销保持） | 每次 ≤10 分钟；力量辐射 ±15°；动态等长 1s×3 ≈ 3s×1；**不影响最大功率、CNS 疲劳、不适合新手** |

## 2. 两条全局规则

- **两周退化规则**：只练速度 → 两周内丢绝对力量；只练绝对力量 → 两周内丢速度 ⇒ **必须每周并发全部素质**——这正是共轭体系存在的生理学依据（与 JTS"并发发展多素质"一致）。
- **月度次数配额**（Ch4）：速度力量+爆发 ~**80 次/月**；力量-速度 ~**16 次/月**。超出配额 = 该素质过度训练的开始。

## 3. mini-max（粘滞点）理论（Ch11）

- 髋伸展峰值 ~150°、膝伸展 ~120°，力量-姿态曲线**因人而异** ⇒ 同样的训练对不同粘滞点的人效果不同。
- **应用**：冲纪录失败的位置 = 功能性等长训练位（卧推顶 2-3 英寸卡壳 → 在该高度做架式等长）；阶梯加载的依据。
- 与 `../exercises/anthropometry-and-weak-points.md` 的人体测量短板分析互补：mini-max 管"角度"，人体测量管"结构"。

## 4. JTS 映射

| Westside 素质 | JTS 技能应用 |
|---|---|
| 最大力量 | W5-8 TS 体系（上限 RPE 8.5） |
| 速度力量/爆发力 | 动态努力/速度课（用户当前计划以爆发力项高翻/高拉覆盖） |
| 向心/起始力量 | 暂停变式（暂停深蹲/暂停卧推/暂停硬拉轮换） |
| 力量耐力 | 容量期 W1-3（双进阶） |
| 离心控制 | 3-1-X-0 类节奏码（../exercises/tempo-and-rest.md） |
