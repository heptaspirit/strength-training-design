# 训前筛查、医学红旗与临床/特殊人群

> 来源：ACSM *Guidelines for Exercise Testing and Prescription* 12th（Ch2 训前筛查、Ch10 其他慢病）+ NSCA *Essentials of Strength Training and Conditioning* 5th（老年阻力训练立场）。
>
> 交叉引用：本文档与 `health/autonomic-cardiovascular-response-heavy-lifting.md`（大重量下头晕/黑视的血流动力学机制）天然成体系——前者管"该不该练/找谁批"，后者管"练的时候怎么不出事"。疼痛相关见 `barbell-medicine/pain-management.md`。

---

## 0. 定位：何时用本文档

本 skill 默认读者是健康年轻男性力量举训练者（如 C2 文档用户）。但真实客户群常包含有基础病或特殊生理状态的人。**出现以下任一信号，先读本文档再决定能否开计划**：

- 用户自述高血压、糖尿病、关节炎、骨质疏松、下背痛史、心衰/肺病等；
- 用户是老年人、青少年、孕期或产后女性；
- 用户问"我有 XX 能不能练""要不要先找医生"。

> ⚠️ **铁律**：本文档是安全筛查与处方边界参考，**不能替代医疗诊断**。凡涉及用药调整、疾病活动期、未控制的心血管/代谢指标，必须建议用户先取得医嘱/转诊，再由其医生决定是否适合运动。

## 1. 训前健康筛查与医学红旗（ACSM Ch2）

### 1.1 两步筛查流程

ACSM 训前筛查是两阶段过程，目标是在开始中-高强度运动前识别需要**医疗 clearance（医嘱）**的人：

1. 判断当前体力活动水平（过去 3 个月是否 ≥3 天/周、≥30 分钟、≥中等强度）；
2. 识别**已知心血管/代谢/肾病**或**提示这些病的体征症状**；
3. 结合**期望运动强度**给出是否需转诊的建议。

无专业人员协助时，可让用户自填 **PAR-Q+**（Physical Activity Readiness Questionnaire Plus）判断是否需先就医。

### 1.2 红旗症状（Table 2.1 精简）

以下任一**新发或异常**症状出现时，应建议医疗评估/转诊，不要直接开大重量计划：

| 红旗 | 可能指向 |
|------|---------|
| 胸部/颈/颌/臂疼痛或压迫感（尤其运动诱发） | 心肌缺血、冠心病 |
| 静息或轻度用力即气短 | 心肺疾病 |
| **运动中**头晕/晕厥 | 严重冠心病、肥厚型心肌病、主动脉瓣狭窄、恶性室性心律失常 |
| 运动后**不久**头晕/即将晕厥 | 健康人也可见（静脉回流减少）——与 A 块 Valsalva/黑视机制呼应，但仍需排查 |
| 踝部水肿、心悸、间歇性跛行、已知心脏杂音、日常活动异常疲劳/气短 | 心血管/代谢病 |

> 💡 **关键定性**：ACSM 明确——**高血压是 CVD 危险因素，不是心脏病**；筛查时按危险因素处理，不自动等同于需紧急转诊。但**未控制的高血压**应在运动前请医生评估。

### 1.3 阻力训练的固有风险

ACSM 原话：关于阻力训练中心血管并发症的筛查证据有限，**目前认为其固有风险较低**（远低于耐力运动诱发的急性事件）。但这不改变"有红旗先筛查/转诊"的原则。

### 1.4 渐进过渡期

对久坐/初动者，ACSM 建议约 **2–3 个月的渐进过渡期**：从低强度（2–3 METs）逐步升到中等强度（3–5 METs），可把急性心血管事件风险压到最低，也减少肌肉骨骼损伤。

## 2. 临床人群处方要点

### 2.1 关节炎（OA/RA，ACSM Ch10）

**核心信息**：运动**不会**加重关节损伤，反而被广泛证实能减痛、抗炎、改善功能。最大障碍是"负重运动会伤关节"的误解（患者和部分医生都有）。

| 维度 | ACSM FITT（关节炎） |
|------|------|
| 频率 | 有氧 3–5 天/周；阻力 2–3 天/周；柔韧每日 |
| 强度 | 有氧 40–59% V̇O₂R/HRR（中）→ ≥60%（剧）；阻力 **60–80% 1RM**（初动者从 50–60% 起） |
| 时间 | 有氧累计 150 分钟/周中强度（或 75 分钟剧强度）；阻力 8–12 次×1–3 组 |
| 类型 | 低关节应力有氧（步行/骑车/游泳/水中）；机器/自由重量/弹力带皆可 |

- 急性炎症期（关节红肿热痛、"发作期"）：**避免大强度运动**，可轻柔全 ROM 活动关节、打破久坐。
- 运动后 48–72 小时明显加痛可能是 DOMS（新手正常），会随适应消退；若某动作持续加重关节痛，换同肌群替代动作。
- 充分热身/冷身（≥5–10 分钟）对减痛极关键。

### 2.2 骨质疏松（ACSM Ch10）

**核心信息**：运动可延缓年龄相关骨流失、降低骨折风险；骨强化只发生在受力的部位。

| 维度 | ACSM FITT（骨质疏松） |
|------|------|
| 频率 | 有氧 4–5 天/周；阻力从 1–2 非连续天/周 → 渐进 2–3 天/周；柔韧 5–7 天/周 |
| 强度 | 有氧中强度（40–59% V̇O₂R/HRR）；阻力"最后 2 次有挑战"，能耐受者用高强度/高速度训练 |
| 时间 | 有氧从 20 分钟 → 渐进 30–45 分钟；阻力 1 组 8–12 次 → ~2 周后进 2 组，每动作 ≤8–10 个 |
| 类型 | 负重有氧优先（步行）；**高冲击/高速度阻力**有益（低-中骨折风险者可用跳/踏箱）；复合动作最佳 |

- ⚠️ **高骨折风险者**：避免脊柱过度屈曲、扭转、受压的动作（部分瑜伽/普拉提体式需评估）；避免爆发性/高冲击负荷。
- 平衡训练（强化股四/腘旁/臀/躯干）对防跌倒骨折很重要。

### 2.3 代谢病（高血压 / 2 型糖尿病）——筛查视角 + 已知收益

> 详细分病 FITT 见 ACSM Ch9（代谢病与 CVD 危险因素）。本文档给教练的安全边界与开局原则。

- **运动收益明确**：有氧 + 阻力训练改善糖化血红蛋白（Church 2010, Dunstan 2002）、胰岛素敏感性、血压（Yang 2014 系统评价：阻力 vs 有氧对 T2DM 均有效）。
- **阻力训练处方（通用起点）**：2–3 天/周，大肌群，中强度起步，渐进加重。
- **未控制者先转诊**：血压/血糖明显未控制、或有红旗症状时，先请医生评估再练。
- **憋气警示**：严重高血压者大重量 Valsalva 可能使血压瞬时飙升（见 A 块 MacDougall 峰值 320/250、个例 >480/350 mmHg），应强调"呼气过粘滞点、屏气 ≤1–2 秒"的呼吸技术，必要时降强度。

### 2.4 癌症生存者（ACSM Ch10，顺带注）

- 运动对绝大多数癌生存者安全且获益大于风险；2019 ACSM 圆桌结论：步行/阻力/柔韧活动前**无需**运动测试。
- **造口患者**：阻力训练时应避免诱发过度腹压（如 Valsalva）——与 A 块呼吸技术直接呼应（专家意见级证据）。
- 骨转移、显著治疗相关副作用（肌少、心脏毒性）者需医疗评估/转诊。

## 3. 特殊人群

### 3.1 老年人 / 肌少症

- 阻力训练对老年人**安全且收益巨大**（Fragala et al. 2019, NSCA 老年阻力训练立场；Chodzko-Zajko 2009, ACSM 老年立场）。
- 原则：从低强度、高次数起步，**渐进**加重（速率可比年轻人慢、增量更小）；多成分组合（力量 + 平衡 + 爆发力 + 柔韧）防跌倒、保功能。
- 即使最虚弱的老年人也应尽量保持能耐受的任何活动量（久坐/卧床对骨量打击迅速且难恢复）。

### 3.2 青少年 / 儿童

- 阻力训练对青少年**安全**（NSCA/ACSM 均认可），前提是技术教学优先、监督到位、循序渐进。
- 1RM 测试在青少年可用，但更推荐 3RM/5RM 估算（见 `intensity/pr-estimation.md`），且需有约 6 个月相关动作经验以保证安全准确。
- 骨骺未闭合者避免极限脊柱轴向负荷与不当技术。

### 3.3 孕期 / 产后

- ACSM 提供 **GAQ-Pregnancy（孕期运动准备问卷）** 与 "get active questionnaire for pregnancy" 作筛查工具。
- 无并发症的孕期在中低风险下可继续/开始运动；有妊娠高血压、前置胎盘、早产风险等**禁忌证**者需医生评估。
- 经期/激素周期对阻力训练力量与肌肥大的影响**很小**（Kissow 2022 等），一般无需据此大幅改动计划；黄体酮期/经前可酌情降强度。

## 4. 决策流程图（教练用）

```
用户有基础病/特殊状态？
  ├─ 有红旗症状（1.2）或疾病未控制？
  │     └─ 建议先医疗评估/转诊 → 拿到 clearance 后再开计划
  ├─ 病情稳定/已控制（如高血压服药达标、关节炎非发作期）？
  │     └─ 按 2.x 的 FITT 起点开计划，渐进加重，强调疼痛监测
  └─ 无红旗、仅年龄/生理状态特殊（老年/青少年/孕期）？
        └─ 按 3.x 原则开计划，技术优先、监督到位
```

> 任何计划中如用户报告**训练相关性疼痛**（非 DOMS），转 `barbell-medicine/pain-management.md` 用 BBM 主动康复框架处理；疼痛 ≠ 全停，优先改计划而非删动作。
