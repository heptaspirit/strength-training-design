# 大重量抗阻训练的自主神经 / 心血管反应

> 来源：MacDougall 1985 / Haslam 1988 / Sale 1994 / Narloch 1995（原始研究）+ NSCA *Essentials* 5th "Breathing Considerations" + ACSM *Guidelines* 12th。
>
> 交叉引用：当用户把"大重量后头晕/走马灯"归因为 CNS 疲劳时，本文档给出另一条独立机制（血流动力学/压力反射事件），并指出管理方式不同（呼吸/支撑技术，而非减容量）。

---

## 0. 先厘清：这不是 CNS 疲劳

`references/consultation/fatigue-sources.md` 把高强度代价归为"神经系统（CNS）疲劳"。但**大重量下的急性头晕/黑视是另一回事**：

- **CNS 疲劳**：神经递质耗竭、中枢驱动下降，恢复需数天至数周，症状是"杠铃异常沉重、不想练"。
- **自主神经/心血管事件（本文档）**：Valsalva 憋气 + 肌肉闭塞解除 → 血压骤降 → 脑灌注不足 → 先兆晕厥。这是**秒级**的血流动力学事件，举完强度一降就快速回血。

> ⚠️ **误判代价**：把"走马灯"当 CNS 疲劳去"降强度减容量"抓不到真因；应按本文档调呼吸/支撑技术。两者可并存，但管理不同。

---

## 1. 举重时的升压机制（三因素）

大重量收缩时动脉压可升到静息的数倍。三个叠加来源：

| 来源 | 机制 | 证据 |
|------|------|------|
| **① 肌内压压迫血管** | 收缩肌内压（IMP）升高直接压迫动静脉；股四头极值文献报到 ~1025 mmHg | MacDougall 1985 |
| **② Valsalva 动作** | 声门紧闭 + 腹壁/胸廓收缩 → 胸腹压骤升 → 进一步推高中心压 | 口腔压测量证实（MacDougall 1985） |
| **③ 交感自主反射** | 非运动区小动脉收缩，维持中心灌注 | Haslam 1988 |

**关键量化（MacDougall 1985, J Appl Physiol）**：双腿蹬举峰值血压均值 **320/250 mmHg**，个例 **>480/350 mmHg**。
**Haslam 1988**：升压随**相对负荷**走，双腿蹬举在 **80% 1RM** 时最猛。
**Sale 1994**：越近极限升压越强；同一绝对重量下，训练后显著下降（适应）。

## 2. "走马灯 / 黑视"到底是什么

> 注意区分：**举中**高血压本身通常不晕；**举后**的急性低血压才会晕。

**"Weightlifter's blackout"（举重者黑视）** 本质是**举后急性低血压**（血压可掉到 25–50 mmHg）致脑灌注不足。机制（trainingweightlifting.com 2017，回引 Compton 1973 / Van Lieshout 2003）：

1. 肌肉闭塞解除 → 血液瞬间涌入下肢（静脉池）；
2. Valsalva 释放 → 胸腹压骤降；
3. 两者共同使回心血量、心输出量瞬降 → 脑灌注不足 → 眼前发黑/走马灯。

**NSCA 5th 官方口径**（"Breathing Considerations"）把该副作用写得明明白白：

> "Be aware, however, that the resulting increase in intra-abdominal pressure has potentially detrimental side effects, such as **dizziness, disorientation, excessively high blood pressure, and blackouts**. This is why the breath-holding phase is—and should be—quite transient, only about **1 to 2 seconds (at most)**. Even a very well-trained individual should not extend the length of the breath-holding phase, because blood pressure can quickly rise to **triple resting levels**."

→ 你的"走马灯"是 NSCA 明列的 Valsalva 副作用之一，**正常但需管理**，不是你"练得太差"或"纯 CNS 累"。

## 3. 可操作处方：呼吸与支撑技术

### 3.1 通用口诀（NSCA 5th）
- **呼气过粘滞点（concentric sticking point），吸气在离心/较轻松段。**
- 适用于绝大多数抗阻动作（如二头弯举：向心过中点呼气，放下吸气）。

### 3.2 有经验者的 Valsalva（仅限高负荷结构动作）
- NSCA 5th：训练有素者做**结构动作**（加载脊柱者，如深蹲/硬拉/肩推）高负荷时，可用 Valsalva 维持脊柱对线与支撑（"fluid ball" 原理，降低椎间盘压缩力）。
- **但必须短暂**：屏气 ≤ 1–2 秒，绝不等到锁定才猛地泄气。

### 3.3 把"憋气"换成"主动呼气"（黑视的直接解法）
**Narloch 1995（Arch Phys Med Rehabil, PMID 7741618）**——最可操作的实证：
- Valsalva 屏气下 100% 1RM 举：动脉压 **311/284 mmHg**；
- 改为**缓慢呼气**下举：直接降到 **198/175 mmHg（p<0.005）**。

→ 过粘滞点/锁定段**主动呼气**（用躯干刚度/腹压扛，而非声门紧闭），能直接削掉血压过山车，是预防"走马灯"的核心技术。

### 3.4 腰带
- NSCA 5th：腰带可帮助维持腹压；**建议用于：加载下背的动作 + 近最大/最大负荷组**。轻负荷或非下背动作不需要。
- 注意：长期过频使用会减少腹肌/下背自身受训机会。

### 3.5 组间
- 慢起慢站、补足水分；避免举完立刻猛站（体位性叠加）。

## 4. 医学红旗：何时不是"训练疲劳"

下列情况**不要**归给训练疲劳，按 ACSM 指南转诊/排查：

| 红旗信号 | 含义 |
|---------|------|
| **真晕**（意识丧失/近乎丧失），非单纯发黑 | 需排查心源性/神经源性 |
| 伴随**心悸、胸痛、呼吸困难** | 心血管评估 |
| 与**负重无关的晕**（日常/躺卧也晕） | 非训练相关，优先就医 |
| 未控制的高血压 / 已知主动脉狭窄等 | 大重量 Valsalva 禁忌或需医嘱 |
| 晕厥反复发作 | 心电/直立耐受评估 |

**上下文注脚（ACSM BFR 信息图 / Patterson 2019）**：BFR 低负荷高次数也能获力量/围度，但会**升 HR/BP、降每搏量**——提示任何"限流 / 憋气 / 大重量"组合都放大心血管应激，医学红旗评估要纳入。

## 5. 与本 skill 的关系

- 补 `fatigue-sources.md` 的盲区：**高强度代价 ≠ 只有 CNS**；急性自主神经/心血管反应是独立维度。
- 当用户报告"大重量后头晕/走马灯"：先用本文档排查 Valsalva/血压机制，再决定是否叠加 CNS 疲劳管理。
- 当用户是"强度敏感型"（见 `consultation/intensity-volume-sensitivity-axis.md`）：高强度日本就易触顶，呼吸技术 + 短屏气 + 腰带是安全底线。
