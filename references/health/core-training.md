## 核心稳定训练（Core Stability Training）

### 为什么核心稳定很重要？

**价值**：
1. **力量传递**：核心刚性 → 力量从腿/臀传递到杠铃
2. **伤病预防**：核心弱 → 下背疼痛/伤病（详见 `references/health/injury-prevention.md`）
3. **动作质量**：深蹲/硬拉/卧推都需要核心稳定

---

### 核心训练分类

| 类型 | 动作示例 | 训练目标 | 安排建议 |
|------|---------|---------|---------|
| **抗伸展（Anti-Extension）** | 平板支撑（Plank）、**Rollout（腹轮 / 杠铃滚动）**、死虫式（Dead Bug） | 抵抗腰椎超伸，建立躯干刚性 | 见下文 Rollout 专项；平板 3×30-60秒 |
| **抗旋转（Anti-Rotation）** | Pallof Press、鸟狗式（Bird-Dog）、单侧推/划 | 抵抗躯干旋转 | 每次训练后：3×10-15/侧 |
| **抗侧屈（Anti-Lateral Flexion）** | 侧平板（Side Plank）、单侧农夫行走、手提箱硬拉 | 抵抗躯干侧屈 | 每次训练后：3×30秒/侧 或 3×20-30米 |
| **后侧伸展（Trunk / Hip Extension）** | 山羊挺身（Back Extension）、RDL、早安式 | 强化竖脊肌与髋伸，抵抗负荷下屈曲 | 跟随后侧链日安排，3×12-15 |
| **爆发力（Power）** | 药球投掷（Medicine Ball Throw）、绳索劈砍（Cable Chop） | 核心爆发力 | 容量期：2×10 |
| **负重（Loaded Carries）** | 农夫行走、负重行走（Waiter's Walk） | 全身稳定性 | 容量期/力量期：3×20-40米 |

> 四类核心功能（抗伸展 / 抗旋转 / 抗侧屈 / 后侧伸展）**应分别覆盖**。典型缺口是前侧抗伸展——多数计划只有 Pallof（抗旋转）+ 农夫行走（抗侧屈）+ 山羊挺身（后侧），抗伸展一格长期空着。

---

### 抗伸展专项：Rollout（腹轮 / 杠铃滚动）

#### 为什么单列

- 深蹲与硬拉对竖脊肌是高刺激，但**对腹肌的肌电需求普遍偏低**（多数研究平均不超过 25% MVIC），三大项不会自动补上前侧抗伸展能力。
- 卷腹 / 仰卧起坐这类屈曲动作只能在"加次数"维度上进阶，且带来重复的腰椎屈曲负荷；rollout 是少数能靠**加长力臂**渐进超载的腹部动作，更契合双进阶逻辑。
- 抗伸展能力对传统硬拉离地、深蹲出坑保持腰椎位置有直接对应；腹部等长支撑训练也被证实可提升最大腹内压与深蹲峰值功率。

#### 变式谱系（按难度递增）

| 变式 | 设备 | 机制与特点 | 适用 |
|------|------|-----------|------|
| **墙面 Rollout** | 腹轮 / 杠铃 + 一面墙 | 站立面墙，向上滚，力臂最短；靠 **后退距离**无级调难度 | 入门、康复期、评估抗伸展基础 |
| **斜面 / 长凳 Rollout** | 手撑长凳或斜面滚动 | 介于墙面与跪姿之间；靠**斜面角度**调难度 | 墙面到跪姿之间的过渡 |
| **跪姿 Rollout** | 腹轮，或杠铃（空杆 / 加小片） | 标准抗伸展，力臂中等，**主力变式** | 绝大多数训练者 |
| **悬吊 Fallout（TRX / 吊带）** | 悬吊带 | 靠**身体倾角**无级调难度（越接近水平越难）；闭链、可换握把 | 缺乏可调器械时最灵活的进阶路径 |
| **Pike / Knee Tuck（脚置轮上）** | 带脚踏的轮（如 Power Wheel）或滑垫 | **髋屈主导**，动态躯干屈曲成分高，**股直肌激活显著高于纯 rollout** | 想额外练髋屈与下腹时；下背敏感者慎用 |
| **站姿 Rollout** | 腹轮 / 杠铃 | 力臂最长，抗伸展 + 前肩稳定双重要求 | 高阶，需先达跪姿全程门槛 |

**差别要点**：

- 纯抗伸展线（墙面 → 斜面 → 跪姿 → 站姿）全程保持脊柱中立，**不产生重复脊柱屈曲**，是力量举训练者的首选主线。
- Pike / Knee Tuck 属**髋屈主导的动态屈曲**变式，股直肌参与高，对下背敏感人群不友好；它不是"更难的 rollout"，而是另一种动作，不要混在同一进阶序列里。
- TRX fallout 的价值在**无级调节**：不需要换器械、不需要加片，只改站姿倾角即可连续调难度，适合器械受限环境（工地健身房、出差）。
- 杠铃 rollout 与腹轮 rollout 在动作模式与刺激上等价，无腹轮时直接用杠铃，不构成设备门槛。

#### 进阶路径

**主线（力臂线）**：墙面 / 斜面 → 跪姿半程（滚到能保持中立位的距离为止）→ 跪姿全程（髋伸展、躯干接近水平）→ 负重跪姿 → 站姿（先斜面或距墙试探，再全幅）

**支线（角度线）**：TRX fallout，由身体接近直立逐步降低到接近水平，作为主线之外的无级补充。

**晋级门槛**：跪姿全程 3×8、离心 2-3 秒、全程无腰椎塌陷与骨盆前倾代偿，才允许进站姿。未达标前**不要靠加次数制造难度**。

#### 剂量

- 3 组 × 6-10 次，离心 2-3 秒，RPE 7-8
- **不做到力竭**：力竭后动作质量崩坏，负荷由腹肌转嫁到腰椎
- 每周 1-2 次即可。有训练经验者极低剂量就能维持（每周 1 组亦有效果），不必堆量

#### 时序与周期落位

- 放在**训练课末尾**，且**避开硬拉 / 深蹲主项之后**——rollout 的失败模式就是腰椎塌陷进伸展，拿已疲劳的下背去接这个风险不划算
- 容量期 W1-3：加入打基础，3×6-10
- 力量期 W5-6：维持 2-3 组，不加量
- 冲刺期 W7-8：降容或退回跪姿小幅度，只做维持
- 醒后 1 小时内不做动态躯干训练（椎间盘水合、内压较高）

#### 风险与禁用

- **失败模式**：腰椎塌陷进伸展、骨盆前倾、用髋屈肌先启动回收 → 负荷转嫁腰椎与小关节
- **禁用**：腰背有症状或处于急性期；肩袖 / 肩前侧不稳定者不做站姿版
- 站姿版对前肩与背阔肌要求显著，上肢有伤时退回跪姿

### 核心训练在周期中的安排

#### 容量期 W1-3

**目标**：打基础，低强度高容量

**推荐组合**：
```
每次训练后：
1. Rollout（跪姿，力臂按能力定）：3×6-10，离心2-3秒
2. 鸟狗式：3×12/侧
3. 侧平板：3×30秒/侧
```

#### 力量期 W5-6

**目标**：维持核心稳定，不堆容量

**推荐组合**：
```
每次训练后：
1. Rollout：3×6-10 @ RPE 7-8（不加量，可负重跪姿）
2. Pallof Press：3×12/侧
3. 农夫行走：3×20米（中等重量）
```

#### 冲刺期 W7-8

**目标**：降容保恢复，核心训练维持但不疲劳

**推荐组合**：
```
每次训练后：
1. 跪姿半程 Rollout：2×8（仅维持，缩短力臂）
2. 死虫式：2×10/侧
```

> **后侧伸展的归口**：山羊挺身 / RDL / 早安式通常已排在后侧链日，核心模块不必重复计算。若计划中没有，则补 45° 反向超伸 3×12-15。
>
> **四类覆盖自检**：抗伸展（Rollout / 平板）、抗旋转（Pallof）、抗侧屈（侧平板 / 单侧负重行走）、后侧伸展（山羊挺身 / RDL）各占一格，缺一格就补，不要三类堆同一格。

### 核心训练的 MRV 审计

**核心肌群 MRV 基准**：≈ 15-20 组/周（所有核心训练合计）

**审计示例**：
```
用户核心训练审计：
- Rollout（每周2次 × 3组）：6组
- 鸟狗式：3组
- Pallof Press：3组
- 农夫行走：3组
- 总计：15组 ≈ MRV 下限 ⚠️ 接近上限，冲刺期需降容
```

**调整原则**：
- 核心训练**不易过度**：过度核心训练 → 下背疲劳 → 影响主项表现
- **优先保证主项恢复**：冲刺期核心训练降容
- **Rollout 体积天然很小**：每周 1-2 次、每次 3 组即够，不要因为"体积小"就加组或加频次——它的限制因素是动作质量，不是容量

## 常见错误

### 核心训练
1. ❌ 核心训练做到力竭 → ✅ 核心训练 RPE 6-7，避免过度疲劳
2. ❌ 冲刺期核心训练不降容 → ✅ 冲刺期核心训练降容 50%
3. ❌ 忽略抗旋转/抗侧屈 → ✅ 核心训练要全面（抗伸展/抗旋转/抗侧屈/后侧伸展）

### Rollout 专项

| 反例 | 为什么 | 正确做法 |
|------|--------|---------|
| ❌ 排在硬拉 / 深蹲主项之后 | 下背已疲劳，rollout 的失败模式正是腰椎塌陷进伸展 | ✅ 放课末，且避开下肢主项日之后 |
| ❌ 每组做到力竭 | 力竭后动作质量崩坏，负荷由腹肌转嫁腰椎 | ✅ RPE 7-8 收组，留 2-3 次储备 |
| ❌ 跪姿没过关就上站姿 | 力臂骤增，代偿必然出现 | ✅ 跪姿全程 3×8 无代偿后再进站姿 |
| ❌ 靠加次数制造难度 | 变成肌耐力训练，抗伸展张力反而下降 | ✅ 加长力臂或加外负荷进阶 |
| ❌ 把 Pike / Knee Tuck 当作"更难的 rollout" | 属髋屈主导的动态屈曲，股直肌参与高，机制不同 | ✅ 单列，作为髋屈/下腹补充，不混入主进阶线 |
| ❌ 拿 rollout 替换 Pallof 或农夫行走 | 三者分属抗伸展 / 抗旋转 / 抗侧屈，不可替代 | ✅ 四格分别覆盖，rollout 只补抗伸展那一格 |
