# 既往伤病史的计划决策框架

> ⚠️ **本文档不能替代医疗诊断**。凡涉及用药、活动期疾病、未控制的症状，必须先取得医嘱。本文档只处理一类问题：**已确诊、已回归、无当前症状的既往伤病史**——用户能否正常训练、要不要限制训练量、怎么监测。

## 1. 核心判据：伤病史本身不是限制条件，当前状态才是

**这是本文档最重要的一条。** 绝大多数孤立性软组织 / 关节外韧带损伤在保守处理后可完全回归负荷。

- **孤立性 MCL 损伤**：血供丰富、位于关节外，愈合能力强，绝大多数保守处理即可回归（LaPrade & Wijdicks, JOSPT 2012）。与 ACL 不同——**MCL 不是"断了不能练"的韧带**。
- **回归负荷的通用标准**（临床指南常用组合）：无痛 + 无关节积液 + 活动度对称 + 等速肌力 ≥90% 健侧 + 专项动作无痛。
- **用户自述"回归训练后无明显反应"即视为已达标。** 达标者**不打折、不加护具、不限制主项重量**。

> ⚠️ **不要把联合伤/术后数据套到孤立性损伤上。** 文献里"2 年股四头肌 deficit 9.7%"这类数字多来自 **ACL+MCL 联合伤 + ACL 重建**人群，不适用于孤立性 MCL 保守治疗者。引用时必须看清人群。

### 1.1 三分类与对应处置

| 状态 | 判据 | 处置 |
|---|---|---|
| **A. 已回归无症状** | 训练中/训练后/日常活动均无痛，活动度对称 | **不限制**。按正常周期推进，只加监测项 |
| **B. 间歇性轻度症状** | 特定动作/角度/负荷下出现，休息后缓解 | **不全局降量**，改**触发式处理**（见 §2） |
| **C. 活动期症状** | 训练中即痛 / 肿胀 / 积液 / 力量下降 | 停止相关动作，转 `barbell-medicine/pain-management.md`；持续 >2 周或夜间痛 → 就医 |

> 判为 B 还是 C 的分界不是疼痛强度，而是**症状出现的位置与是否随休息缓解**。B 类最容易被误当成"需要全面保守"，从而把本可推进的计划拖平。

## 2. 触发式监测 vs 预防性降量（本框架的核心操作）

多数教练的默认反应是"有旧伤 → 全程降量 / 加护具 / 删动作"。这个做法的问题是：**它把一个可监测的信号变成一个永久性的负担，并且掩盖了真正的适应能力**。

**正确做法**：不加预防性限制，只在**明确的触发条件**出现时做**局部**处理。

| 触发条件 | 处置 | 不动什么 |
|---|---|---|
| 某类负荷下出现特定症状 | 降该类负荷的**量或角度** | 总周期进度不减 |
| 出现新的动作模式不适 | 降级/暂停**该动作** | 其他动作不减 |
| 症状在训练后持续 >24h | 该动作减量 30-50%，或改同肌群替代 | 主项可维持 |

> **关键区别**：降的是**触发它的那个负荷**，不是**整个计划**。这与"激进/保守"是两个独立维度——触发式处理让你能保持激进而不付代价。

### 2.1 何时该重新分类（从 A 降到 B/C）

- 伤病部位在**新增负荷模式**下出现不适（如既往膝伤在做某种新下肢动作时）
- 出现**训练中即痛**（而非训练后）——这是负荷超过容量的信号
- 出现**关节积液 / 肿胀 / 活动度下降**——结构性信号，优先于训练计划讨论
- 症状**逐周加重**而非波动

## 3. 相邻结构误诊（临床高频）

**膝内侧疼痛的三个高仿来源**——位置极近，临床上互相误诊率高：

| 结构 | 位置 | 典型诱发 | 关键鉴别 |
|---|---|---|---|
| **MCL** | **关节线本身**，内侧副韧带 | 外翻（valgus）应力 | 外翻受力时痛，可能伴积液 |
| **鹅足（缝匠肌+股薄肌+半腱肌联合腱膜）** | **关节线下方**的胫骨内髁骨性突起 | 反复屈伸、容量突增、**足过度旋前**、腘绳/股四失衡 | 骨性突起上**明确压痛点**；深蹲/上楼/伸膝加重 |
| 内侧半月板 | 关节线 | 屈曲+旋转 | 关节内机械感、卡顿、锁住 |

> ⚠️ **鹅足肌腱炎常被误诊为 MCL 拉伤**（两者仅隔一层浅滑囊）。用户报"膝内侧不适"时，**先问痛点相对关节线的位置**——这一句就能分流。

**前肩痛的鉴别谱**（按临床常见度）：

| 结构 | 典型特征 |
|---|---|
| **肱二头肌长头肌腱**（最常见） | 前肩沟可复现压痛；过顶/屈肘抗阻诱发 |
| 肩胛下肌（肩袖前部） | 内旋痛、lift-off 征阳性、交叉抱体痛——**易被漏诊**（临床注意力多在上冈肌） |
| SLAP 唇盂损伤 | **深部关节内痛** + 卡顿/弹响 + 不稳感；过顶活动诱发 |
| 肩峰下撞击 | 外侧为主；Neer / Hawkins-Kennedy 阳性 |
| 颈椎来源 | 伴颈症状、放射至肘下、麻木刺痛 |

### 3.1 "只在拉伸时不适、训练中无感"的判读

**这组症状本身是低风险信号**。逻辑：负荷路径（收缩）下无症状 → 没有组织在承重时被激惹的证据；静态牵拉下的不适更可能来自**肌肉/关节囊的静态张力**，而非损伤。

**但要与计划交叉检查**：新增的过顶推举类动作（实力推、借力推、严格过顶）会首次把肩带入此前未使用的角度。**若该动作在训练中出现前肩痛 → 降重或暂停该动作**，不是永久放弃。

**升级信号（出现任一项才建议就医）**：
1. 过顶推举时出现前肩痛
2. 晨起时肩前方痛
3. 主动内旋痛或交叉抱体痛（提示肩胛下肌）
4. 弹响 / 卡顿 / 不稳感（提示 SLAP）
5. 深部关节内痛（区别于表面酸痛）

## 4. 部位监测信号表

### 4.1 膝（MCL 史 / 鹅足史）

| 监测项 | 怎么看 | 触发后 |
|---|---|---|
| **膝内扣** | 末组结束时录像回看，或让训练者自己数 | 降重 + 加髋外展 / 膝内扣控制 |
| 鹅足压痛 | 触诊**关节线下方**骨性突起 | 降鹅足所属肌群（腘绳肌）训练量 + 查足旋前 |
| 关节积液 | 晨起对比双侧髌上围度 | 停止相关动作，转诊 |

> **MCL 的力学提示**：MCL 是**外翻应力**下的主要约束，而深蹲中负荷最大的恰是**膝内扣**。因此 MCL 史的**唯一相关负荷路径是深蹲加重期的膝内扣**，不是"深蹲本身"。有 MCL 史但无膝内扣者，不构成深蹲限制。

### 4.2 肩（前肩不适史）

| 监测项 | 触发后 |
|---|---|
| 过顶推举类动作（实力推 / 借力推）出现前肩痛 | 降重或停该动作 1 周 |
| 面拉末端 / 肩胛下沉位是否还能守住 | 回到稳定类变式（见 `exercises/weak-points.md` 卧推行） |
| 夜间痛 / 晨起痛 | 就医 |

### 4.3 腰（下背痛史）

| 监测项 | 触发后 |
|---|---|
| 硬拉/相扑硬拉中躯干刚性 | 回到 `health/core-training.md` 的抗伸展 + 呼吸重建 |
| 晨起僵硬 | 减容 + 就医排查 |

## 5. 记录规范

伤病史进入计划文档时，**只写会改变计划的内容**：

| 该写 | 不该写 |
|---|---|
| 诊断名 + 当前状态（A/B/C 分类） | 完整病史与就诊经过 |
| 会受限的**具体负荷路径** | 与计划无关的既往伤 |
| 触发式监测项 + 触发阈值 | 预防性限制（除非有医学依据） |
| 复查条件 | "注意安全"类空话 |

> 单个训练者的具体伤病史**不进本 skill**，落在其计划文档内——本文件是可复用于任何训练者的判据框架。
