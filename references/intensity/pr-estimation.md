# PR 估算流程（用户未测试过 1RM 时）

> 本文件提供完整的 PR（1RM）估算方法，适用于未测试过 1RM 的用户。
> 估算结果仅作为计划起点，实际训练中通过 RPE 快速校准。

## 一、背景

很多用户没有测试过自己的 1RM，但有过训练经验（如做过 5×5 训练），且能感受 RPE。

应按以下流程引导用户，估算其当前 PR。

---

## 二、估算方法

### 方法一：AMRAP 测试估算（推荐）

引导用户做一组 AMRAP（As Many Reps As Possible），然后根据重量和次数估算 1RM。

**引导话术**：

```
"你有没有做过 AMRAP 测试？就是选一个重量，看自己最多能做几次。

如果没有的话，可以现在测一下：
选一个你能做 3-5 次的重量（感觉像是 RPE 8-9），做 AMRAP，记录重量和次数。

我来帮你估算 1RM。"
```

**估算公式**（Epley）：

```
1RM ≈ 重量 × (1 + 次数 / 30)
```

**示例**：
- 用户用 100kg 做了 5 次 AMRAP（RPE 9）
- 估算 1RM = 100 × (1 + 5/30) = 100 × 1.167 ≈ 116.7kg
- 取保守值：115kg 作为参考 PR

---

### 方法二：根据训练经验估算

如果用户连 AMRAP 也没做过，根据其训练水平和经验给保守估算值。

|---------|------|---------|-------------|

| **新手（<1年）** | 女 | 体重倍数法 | 深蹲 ≈ 0.8×体重，卧推 ≈ 0.6×体重，硬拉 ≈ 1.0×体重 |
| **中级（1-3年）** | 男 | 体重倍数法 | 深蹲 ≈ 1.5×体重，卧推 ≈ 1.2×体重，硬拉 ≈ 1.8×体重 |
| **中级（1-3年）** | 女 | 体重倍数法 | 深蹲 ≈ 1.0×体重，卧推 ≈ 0.8×体重，硬拉 ≈ 1.3×体重 |
| **高级（3-5年）** | 男 | 体重倍数法 | 深蹲 ≈ 1.8×体重，卧推 ≈ 1.4×体重，硬拉 ≈ 2.2×体重 |
| **高级（3-5年）** | 女 | 体重倍数法 | 深蹲 ≈ 1.3×体重，卧推 ≈ 1.0×体重，硬拉 ≈ 1.7×体重 |

1. 先用表1给保守估算值作为计划起点
2. 在训练中用 RPE 调节，2-3 周内找到真实 PR
3. 参考表2和表3，了解自己的水平在人群中的位置
4. 不要盲目追求高倍数，技术水平和伤病历史同样重要

### 方法三：通过"能做X次的重量"反推

引导用户回答以下问题：

```
"你目前能用某个重量做几次？比如：
- 深蹲：用 XX kg 能做 YY 次
- 卧推：用 XX kg 能做 YY 次
- 硬拉：用 XX kg 能做 YY 次

告诉我这些数据，我来帮你估算 1RM。"
```

然后用 RPE 表（见 `references/intensity/rpe-reference-and-progressive-overload.md`）反推：

- 例如：能做 5 次 → 约 RPE 8 → 约 80% 1RM → 1RM ≈ 重量 / 0.8

---

## 三、重要提醒

1. **保守估算值仅作为计划起点**，实际训练中通过 RPE 快速校准（2-3周内就能找到真实 PR）
2. **个体差异显著**：体重倍数表是人群平均值，实际能力可能因技术、肢体长度、训练专注度而异
3. **不要盲目追求高倍数**：技术水平和伤病历史同样重要
4. **定期重测**：每 8-12 周可重测 AMRAP 或 1RM，更新 PR 数据

## 四、标准 1RM 测试协议（NSCA）

当用户**已具备中级以上训练经验、动作技术扎实**且想直接测真 1RM 时，按 NSCA 流程（比 AMRAP 估算法更准，但应力更大，需技术+监督到位）：

1. **热身**：轻重量做 5–10 次轻松完成。
2. 休息 **1 分钟**。
3. **保守极限负荷**：加 5–10%（上肢）或 10–20%（下肢）做 **2–3 次**；休息 **2 分钟**。
4. 继续以 **递增负荷** 逼近 1RM，每组间休息 **2–5 分钟**（大重量恢复关键）。
5. 通常 **3–5 次试举** 内测出真 1RM；负荷增量按绝对重量调整（强者蹲 225kg 可每次 +9–14kg，弱者 +4–9kg 更精确）。
6. **安全**：核心/多关节动作优先（大肌群耐受重负荷）；稳定肌弱的孤立/俯身类（如俯身划船）不宜做 1RM（易失技术、测试无效）；需保护者/深蹲架。

> ⚠️ **不适合直接测 1RM 的人群**：未训练者、无经验者、伤病中、需医学观察者。此类改用 **3RM/5RM 估算**（NSCA 推荐：忽略训练状态会使 1RM 测试不安全且不精确）。青少年需约 6 个月相关动作经验才适合。

### 用 xRM 估算 1RM（替代方案）

- 测 **3RM/5RM** 后用 Epley 或查 %1RM 表反推（见 `intensity/rpe-reference-and-progressive-overload.md` 的 RPE↔%1RM 表）。
- ⚠️ NSCA 提醒：**次数越多，预测 1RM 越易偏高（overestimate）**；且受该人熟悉哪种训练影响。因此**低次数（1–5RM）估算更准**。
- 爆发力动作（高翻/高抓）不适合 >5RM 重复测试（技术会快速崩）。

## 五、Epley 与 Brzycki 交叉核对

本文件主用 **Epley**：`1RM ≈ 重量 × (1 + 次数/30)`

另可用 **Brzycki**（对中低次数 1–10RM 更稳）交叉核对：

```
1RM ≈ 重量 × 36 / (37 − 次数)
```

**用法**：同一组 AMRAP 数据，用两公式各算一次，若结果接近 → 估得稳；若差距大（尤其次数 ≥8 时 Epley 常偏高）→ 取偏低值作保守 PR，并在训练中 2–3 周用 RPE 校准实测。

> 设计器现行取整：AMRAP 估 1RM 后**向下取整至 2.5kg**（用户片配置），保守起步。

### ⚠️ 读数前提：AMRAP 必须是力竭组（或已到 RPE 9）

Epley / Brzycki 的自变量是「**力竭**次数」。若用户在测试中**因姿势崩坏、稳定性失效或安全考虑提前收组**，完成次数 < 力竭次数，两个公式都会**系统性低估**——而且低估的方向恰好会把真实进步抹掉。

| 停止情形 | 处理 |
|---------|------|
| 做到 RPE 9–10 才停，**末次速度仍可控** | 按完成次数直接套公式 ✅ |
| 末次**速度已明显衰减**（还能完成，但明显变慢） | 按完成次数套公式，**取区间下沿**（见下） |
| 因"姿势散 / 晃 / 轨迹漂"提前停，且自述**仍有第 2-3 次余力** | **改用 RPE 换算**：查 RPE↔%1RM 表，`e1RM = 重量 ÷ 对应 %1RM`；并标注该值为下界 |
| 自述"完全推不动"但次数远低于预期 | 按完成次数算，同时排查当日状态（睡眠/饮食/前序训练干扰） |

**两类"提前停"方向相反，不要混为一谈**：

- **姿态失守**（晃 / 轨迹漂 / 姿势散）→ 收缩力量尚未到顶 → 公式**低估**，必须改用 RPE 换算，否则会把真实进步读成"零增长"；
- **速度衰减**（动作变慢、还能完成但明显吃力）→ 已接近真实力竭 → 主观 RPE 常**偏低**（速度是比感觉更早的力竭指标）→ 套公式时取**下沿**，不取上沿。

> 硬拉对速度衰减尤其敏感：离地速度一掉，后续次数的风险与回报同步恶化。**末次速度明显变慢即可收组**，不必等主观到 RPE 9.5（JTS 对硬拉"不堆容量、不追次数"的立场与此一致）。

> **测试条件也要记**：多个主项分别测试时，**间隔 ≥2 天、优先测最重项**。前一项的残余疲劳（尤其上背、躯干）会集中在"稳定系统"上，直接压低后一项的次数。

**示例（示意，用整数便于核算）：AMRAP 100kg × 4，自述"末两次开始晃、但仍有第 2 次余力"（RPE 8.5）**

| 数据来源 | 换算 | e1RM |
|---------|------|------|
| 该 AMRAP | 机械套 Epley：100×(1+4/30) | 113.3 → 112.5（**低估**） |
| 同上 | 按 RPE 8.5 / 4 次 = 85%：100 ÷ 0.85 | **117.6** |
| 一周前顶组 110kg × 2 @ RPE 9（92.5%） | 110 ÷ 0.925 | **118.9** |

两组独立测点收敛 → 真实 e1RM ≈ **117.5**，而非 112.5。**只按完成次数套公式，5kg 的进步会被读成"零增长"。**

**示例（示意）：150kg × 5 @ RPE 9，末次速度已明显衰减**

| 口径 | 换算 | e1RM |
|------|------|------|
| 按完成次数 | Epley：150×(1+5/30) | 175.0 |
| 同上 | RPE 表 9 / 5 次 = 85%：150 ÷ 0.85 | 176.5 |
| 同上（速度修正，按 RPE 9.5 / 87.5%） | 150 ÷ 0.875 | 171.4 |

三口径落在 171–177 → **取区间下沿 172.5**（不取上沿）。
反向校验：150 ÷ 172.5 = 87.0%，5 次 @ 87% ≈ RPE 9.3，与主观报告吻合。

> 推论：AMRAP 记录必须同时写 RPE 与**停止原因**（力竭 / 姿态 / 速度 / 安全）——它是决定"结果向哪边取整"的分叉点。
