## JTS 自我调节原则

### 核心规则

1. **TS 是「探测」而非力竭组**  
   - TS RPE 目标 8-8.5（力量期）或 9（冲刺期）
   - 如果 TS RPE 达到 9.5-10 → **下次训练降低 TS 重量 5-10kg**

2. **BO 是「积累」而非力竭组**  
   - BO RPE 目标 7-8（比 TS 轻松）
   - 如果 BO RPE 超标 → **下次训练降低 BO 重量 5-10kg**

3. **TS 当天 RPE 比预期高 2 点以上** → **减少 BO 组数 1 组**（3→2，或 2→1），保 TS 质量

4. **连续 2 周 TS RPE 超标** → **插入额外减载周**

## 自我调节工作流

### 训练当天

```
1. 热身组：用轻重量（50-60% TS 重量）做 2-3 组 × 5 次
2. TS 组：按计划重量试探
   - 如果 RPE 比预期低 → 下次增重 2.5-5kg
   - 如果 RPE 符合预期 → 维持或小幅增重
   - 如果 RPE 比预期高 2 点以上 → 减少 BO 组数
3. BO 组：按降重 8-12% 执行
   - 如果 BO RPE 过高 → 下次降低 BO 重量
```

### 训练后记录

在用户指定的笔记软件中记录：
```
W5 深蹲 TS 117.5×5
- 计划 RPE：8
- 实际 RPE：8.5
- 结论：符合预期，下周增重 2.5kg

W5 深蹲 BO 107.5×5 ×3
- 实际 RPE：7.5
- 结论：符合预期，维持降重 8.5%
```

## TM 自动调节（基于 SBS RIR 版机制）

> 来源：SBS Strength Program Last Set RIR（Greg Nuckols / Stronger By Science）。用「训练最大值 TM」代替固定 PR：每周按末组 RIR vs 目标自动增减 TM，工作重量 = TM × 当日 %。**优点：TM 自适应涨跌，用户始终用「刚好合适」的重量训练，无需反复测 1RM。**

### TM 自动调节 7 档表

| 情形（与目标 RIR 对比） | TM 变化 |
|------------------------|---------|
| 完成组数不足 2+ 组 或 末组 RIR 远低于目标 | **-5%** |
| 少完成 1 组 或 末组 RIR 略低于目标 | **-2%** |
| 完成目标组数且末组 RIR 达标 | **0%** |
| 末组 RIR 高于目标 1 | +0.5% |
| 高于目标 2 | +1% |
| 高于目标 3 | +1.5% |
| 高于目标 4 | +2% |
| 高于目标 5 及以上 | **+3%** |

- 默认组数目标 5 组（可调 3-7，按动作疲劳倾向，如硬拉可降到 3）
- TM 只用于计算当日工作重量，可能显著高于/低于真实 1RM，不必纠结
- 从保守 TM 起步：若估算偏低，几周内自动爬升到位；估算偏高，自动回落

### Single @8 当日调节锚（推荐）

主项工作组前，做 1 次 @ RPE 8（约 90% 1RM，可按动作调 87-93%）：

1. 热身后逐组加重至「RPE 8 的单次」
2. 把该重量填入「single @8」→ 自动更新 TM（TM = 单次重量 ÷ 90%）与**当日**工作重量
3. 效果：当日状态实时反映到重量上，且预热单次本身有神经激活价值

> 经验数据（Nuckols）：定期做 overwarm single（85-93%，即使不用于调 TM）对进步有正向贡献。

### 减载周规则（SBS 硬编码）

减载周（W7/14/21）：**无 RIR 目标、TM 不动**，固定 4-6 组按列出的重量完成即可，辅助/上背也减量。减载是「恢复」不是「刺激」。

### 与 skill 现有 RPE 体系的衔接

- TM 自动调节 = skill「渐进超负荷 + RPE 调节」的**表格化实现**：RPE 评估末组余力 → 映射到 TM 增减
- 适用于：希望少做决策、按数据推进的用户；或作为动态 PR 调整（见 `rpe-reference-and-progressive-overload.md` 第六节）的替代机制
- 保留 skill 底线：主项 TS 上限 RPE 8.5 仍适用（TM 调节不改变力竭管理）

## RPE 校准练习

### 新手如何学会 RPE

1. **从 8 RPE 开始练习**：用 70-75% 1RM 做组，体会「还能做 2 次」的感觉
2. **对比 6 RPE 和 8 RPE**：同一动作，轻重量 vs 中等重量
3. **录像对比**：RPE 8 的技术 vs RPE 9.5 的技术（变形明显增加）

### RPE 常见的偏差

| 偏差 | 原因 | 修正 |
|------|------|------|
| RPE 低估（实际 9，自估 7） | 不想承认累了 | 录像复盘 |
| RPE 高估（实际 7，自估 9） | 过度谨慎 | 尝试加量，看是否真力竭 |
| RPE 波动大 | 恢复不足（睡眠/营养） | 先改善恢复，再练 RPE |

## 常见错误

1. ❌ TS 做到力竭（RPE 10） → ✅ TS 最多 RPE 9（冲刺期）
2. ❌ BO 和 TS 一样重 → ✅ BO 必须降重 8-12%
3. ❌ 每次训练都改变计划 → ✅ RPE 调节是「小幅渐进」，不是每天变
4. ❌ 忽略 RPE 做完全固定计划 → ✅ RPE 的价值就是自我调节，固定计划不如用 %1RM
