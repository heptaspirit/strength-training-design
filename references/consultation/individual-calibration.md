# 个体校准层

> 依据：基于 Foster 等 (2001) 的 sRPE × 时长负荷量化方法；校准阶梯的级差判据与"哪些量可个体化"为工程约定。模型结构与全部系数见 `references/consultation/session-strain-modeling.md`，评分协议与拟合步骤见 `references/consultation/srpe-calibration.md`。

## 0. 两层架构

模型分两层，各管一件事，**不要混着改**：

| 层 | 住在哪 | 谁维护 | 允不允许改 |
|---|---|---|---|
| **基线层**——模型结构、动作库系数、时间常数、崩坏判据 | 技能仓库 | 技能维护者 | 只在发现**方法层面**错误时改（公式、系数、判据写错了） |
| **校准层**——参考 1RM、时长口径、课型 sRPE 基线、单次上限 | 使用者自己的工作空间 | 使用者 | 随时按自己的数据改 |

**为什么必须分层**：基线层的价值在于「任何人拿到都能跑」——它不带任何人的数字，所以能当公共尺子。校准层的价值在于「比公共尺子更贴合这个人」——它一定带个人数字，一旦回流进基线，公共尺子就被绑死在第一个人身上，第二个人用不了。

推论：**改基线层永远是"修模型"，改校准层永远是"调参数"。** 觉得读数不对时先问是哪一层的问题——绝大多数情况是校准层缺数据，不是基线层算错。

## 1. 基线层给什么，不给什么

**给（拿到就能用，不需任何个人数据）**：

1. **单日内部的排序**——哪个动作更贵、谁排在谁后面会崩。纯结构，与参数无关。
2. **动作落点的排除法**——把明显违规的排法秒级刷掉。
3. **代价转移的方向**——"减它前面的总量"与"把它往前挪"哪个更有效。
4. **疲劳账本**——逐动作可拆、可复算、可审计。
5. **局部肌群链**——哪个动作落在链条受限位置。

**不给（必须靠校准层补）**：

1. **绝对量级**——"峰值周是 W3 不是 W7""这周比上周重多少"这类跨课型比较。同一对比在不同参数下幅度可差 2-3 倍（结构稳、幅度不稳）。
2. **"过没过"的阈值**——需要 AU 与后果变量的实测对应关系。
3. **A → sRPE 的换算**——见 §4。
4. **个人局部代价**——模型看不见握力、等长脊柱负荷、速度需求、组间休息自由度。

## 2. 校准阶梯（L1 → L5）

**逐级升高，够到哪级用哪级，不要跳级。** 跳级的典型症状是拿 L1 的数据去做 L4 的结论——样本量根本不够，结论看着精确实则不可复算。

| 级 | 校准什么 | 需要多少数据 | 产物 | 可靠边界 |
|---|---|---|---|---|
| **L1** | 参考 1RM（杠铃动作） | 1 次测试或 AMRAP 估算 | 参数文件的 `one_rm` | 只影响相对强度计算；ref **整体**平移不改排序，改的是 ref **之间**的关系 |
| **L2** | 时长口径 +课型系数 | 3-5 次（同一计时起止点），每课型≥2 次 | 按课型的实测/模型时长比值 | **课型内**极差 >1.5 倍 = 计时不稳，**禁止进入 L5**；课型间偏 = 模型对该课型估计有偏，记课型系数即可（不是停止理由） |
| **L3** | 课型 sRPE 基线表 | 每课型 ≥5 次 | 按课型的时长中位 + sRPE 中位 + 带宽 | 只在**同一课型 + 同一周期结构**内可比 |
| **L4** | 单次 AU 上限 | 「全」与「部分/未」两组各有样本 | 可执行阈值 | 两组 AU 区间重叠时画不出线，需引入外部变量 |
| **L5** | k = AU/A 的换算 | n ≥10 且跨 ≥2 课型，且**课型内** k 极差 <1.5 倍、课型内方向一致率 ≥70% | 回归系数（可选） | **可选级**，多数情况永远不需要。**课型间** k 极差不作判据 |

### L1 是唯一无条件该做的

参考 1RM 不需要任何拟合——它是你已经知道的东西。缺了它，模型要么报错（内置动作库不带默认 ref），要么你拿一个错的量级去算相对强度。它也是**最值得校准的一级**：把某个变式的参考 1RM 调低，模型会立刻显示出"这个变式相对主项在退化"，这类信息比任何量表都早。

### L2 是最容易被跳过、也最致命的一级

AU = sRPE × **实际时长**，时长项由训练者自主控组间歇决定——模型看不见它。实测时长与模型时长若口径不一致（例如模型只算工作组、实测含热身），k 的离散几乎全部来自这一项，此时无论怎么拟合都是错的。

**判据要拆成两个数字看**，因为它们指向完全不同的处置：

| | 含义 | 超限时的处置 |
|---|---|---|
| **课型内**极差 | 同一个课型内部，实测/模型比值的离散 | **个人计时口径不稳** → 回去统一计时起止点，禁止进入 L5 |
| **课型间**极差 | 不同课型的比值中位之间的差距 | **模型对该课型的时长估计有系统性偏差** → 记课型系数，不是停止理由 |

实测见过第二种：某个课型的实测时长恒为模型估的 0.7，另一个课型恒为 1.1，而课型内极差只有 1.03 倍。**这时要求使用者"统一计时"是错的——他本来就很稳，是模型估偏了。**

**课型系数怎么记**：比值 = 实测时长 / 模型时长，按课型记下这个数。之后读该课型的模型时长时先乘上它，`A` 的相对强度不变、时长读数变准。系数落在使用者参数文件里，基线公式不改。

### L3 是大多数人的终点，且完全够用

多数训练者到 L3 就停，这是**正确终点**，不是半成品。L3 给的是漂移检测能力：同课型固定结构下 sRPE 偏离基线 >1 档 = 有变化。这时候该怀疑的是计划改动（换动作、加量、减重、测试周），不是模型。

### L5 是可选级，不是成熟度标志

见 §4。

## 3. 校准报告脚本

```bash
python scripts/calibration_report.py --log srpe_log.csv \
    [--sessions c3_sessions.json] [--params my-params.json] [--anchor 12.5] [--json]
```

脚本只出报告与判定，**不写任何参数文件**。

| 参数 | 作用 |
|---|---|
| `--log` | sRPE 日志 CSV。列名兼容 `date/session/session_type/A_model/duration_min/srpe/outcome` 及其中文别名（`日期/课型/A/时长/sRPE/完成度`） |
| `--sessions` | 会话 JSON（`session_strain.py --input` 的输入格式）。按「周次 + 周几 + 课型」匹配日志行，**自动填 A 并同时算出模型时长**（L2 需要） |
| `--params` | 参数 JSON，用于算 A 时用你自己的参考 1RM |
| `--anchor` | 锚点 A，A% 刻度的分母 |
| `--json` | 结构化输出，便于跨期对比 |

报告分六节，逐级对应 L1-L5：

1. **覆盖度**——各课型 n、A/时长/sRPE 中位；单课型与 n<5 会明确点名
2. **L2 时长口径**——按课型给实测/模型时长的比值，**课型内与课型间分开判**：前者超限 = 个人计时不稳（禁止进入 L5），后者超限 = 模型对该课型估偏（记课型系数，不是停止理由）。未给 `--sessions` 时跳过并提示补法
3. **Step 1诊断**——AU vs A 的 r / rho（标注为「跨课型混合，仅供参考」）、AU vs 时长的 rho（对照项），以及两个**有判据**的量：课型内方向一致率、课型内/课型间隐含 k 极差
4. **L3 课型基线表**——按课型的时长中位、sRPE 中位、带宽、漂移行
5. **L4 单次上限**——需要「全」与「部分/未」两组；区间重叠时拒绝画线
6. **L5 判定**——按级给出 ok / stop / skip 与理由

**脚本的三条设计取舍**（都是为了防止"看起来对"的结果）：

- **课名匹配不用子串猜**，用「周次 + 周几 + 课型」三个 token 判定。日志写「周一 深蹲日（W2）」、会话 JSON 写「W2 周一 深蹲+垂直推」要能对上；锚点课（无周次）不得顶替当周实测课；匹配到多节时**留空并点名**，不挑一个最像的。
- **判定只用课型内证据**：课型内 k 极差、课型内方向一致率。跨课型混算的 rho 与课型间极差都不作判据，原因见 §4。
- **判定顺序先报最强的停止信号**：课型内 k 极差超限比"样本不足"更有指导意义——两者都指向"别拟合"，但前者指出了具体原因。
- **单课型不出拟合结论**：跨课型混合会把周期形状当成个人特征；只覆盖一种课时，回归系数只对该课型成立。

## 4. k 拟合：为什么多数情况该跳过

L5 常被误解为"模型准了"这一步。实测多数情况不成立：

**k = AU/A 这个换算需要一个常数 k，而它在原理上就断了。** AU 的分子含实际时长，时长由训练者控组间歇决定，模型不预测它。实测同一套动作结构下实际时长 55 → 66min（+20%），AU 随之差 31%，而模型 A 只差 3%——**差值几乎全在模型看不见的那一项里**。此时相关系数可以很好看，隐含 k 却能差 2.7 倍。

四条硬约束，任一不满足即**停止拟合**：

| 门 | 阈值 | 为什么 |
|---|---|---|
| **课型内**隐含 k 极差 | >1.5 倍即停 | 同一课型内部就对不上，说明 A 与 AU 不是线性关系，加变量救不回来 |
| **课型内**方向一致率 | <70% 即停 | A 涨了而 AU 没涨。课型系数按课型缩放、不改课型内的排序，救不了这种 |
| 样本量 | n <10 即停 | 小样本单周期拟合出的曲线往往是**这个周期的形状**，不是这个人的特征 |
| 课型覆盖 | <2 种即停 | 系数无法跨课型验证，只对单一课型成立 |

**课型间极差不在这张表里。** 课型间 k 能差好几倍是**正常且预期**的——A 的课型间刻度本来就没校准过（且因局部代价系统性低估，见 `session-strain-modeling.md` §4.2），拿它当停止信号等于用一把没刻度的尺子量东西，测出的差距是尺子的。处置是在校准层按课型记系数（§2的 L2），不是禁止拟合。

停止后不是没事可做——**转 L3 查表 + 漂移检测**，它对数据量的要求低一个量级，且能回答实际排期问题（同课型 sRPE 偏离基线 >1 档 = 有变化）。

**外推禁令**：拟合出的 k 不能跨周期结构使用。容量期与力量期（TS + BO、RPE 8.5、%1RM 0.85+）无重叠，减载周同理；体重变化使绝对强度与 1RM 全部漂移。

## 5. 校准纪律

1. **基线层在单次校准过程中一律不改。** 发现读数不合意，先怀疑校准层缺数据或口径不一致，不改基线代码与文档。校准产物只落使用者工作空间的参数文件，通过 `--params` 传入。
2. **示例与判据里不带具体训练者的实测数值。** 用整数示意代替，否则基线会被绑死在第一个人身上。
3. **锚点中途不换。** A% = A / A_anchor，A_anchor 是一次**已完成且恢复过来**的训练课。换锚点后此前所有 A% 读数作废。
4. **审计脚本必须与计划同步。** 改了计划却没改生成训练课的脚本，报告会继续审计一个已不存在的计划——且因为它"看起来对"，很容易被忽略。
5. **1RM 变了要重跑。** L1 是所有相对强度的基础，改了它 A / Rf / 惩罚全部读数都变。

## 6. 校准不能做的事

即使做到 L5，下面这些仍然不成立：

- **不作绝对日间负荷断言**——「峰值周是 W3」「这周比上周重多少」。结构稳、幅度不稳。
- **不作计划生成器**——计划由训练学规则决定，模型只在合法落点集合内排序。
- **不追踪握力、等长脊柱负荷、训练时长、速度需求**——四处盲区，遇到时以训练学判断为准。
- **不用来预测"今天会不会累"**——模型是称重秤：刻度可校准、可漂移、可重设，但"这个杠铃比那个重"在秤上是事实，它测不出"今天会不会累"。

判读这三层的分工、以及为什么缺一层都会出错，见 `references/consultation/session-strain-modeling.md` §0.4。

## 7. 来源
