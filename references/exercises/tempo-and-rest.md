## 1. 为什么需要节奏与休息参数

现有计划体系对辅助动作只规定「组次 + RPE」，但**肌肥大的刺激质量还取决于两个正交变量**：

| 变量 | 作用 | 缺失时的后果 |
|------|------|-------------|
| **节奏（Tempo）** | 控制每次重复的离心速度与停顿，决定机械张力密度（TUT） | 只写「3×8」时，快速借力重复稀释了目标肌群的张力时间 |
| **休息（Rest Per Set）** | 控制组间恢复程度，决定代谢压力累积与训练密度 | 休息过长 → 代谢压力不足；休息过短 → 组间掉重量、动作质量崩 |

这两个参数与 skill 现有的 RPE（强度）、双进阶（渐进超负荷）、MRV 审计（容量）**正交**，可叠加使用、互不冲突。

## 2. TUT 节奏码定义

### 2.1 四位数编码

节奏码用 **4 位数字**表示一次重复的四个阶段（单位：秒）：

```
[离心] - [底部停顿] - [向心] - [顶部停顿]
```

- **离心**（下降）：控制下放速度，是肌肥大张力时间的主要来源
- **底部停顿**：消除牵张反射（SSC），增加张力时间与动作控制难度
- **向心**（举起）：一般 1 秒（爆发向上）或 2 秒（控制）
- **顶部停顿**：消除惯性回弹，常用于增肌控制

### 2.2 常用码表

| 码 | 含义 | 适用场景 |
|----|------|---------|
| `4111` | 4s 离心 - 1s 底部 - 1s 向心 - 1s 顶部 | 增肌日基础节奏：张力时间最长，适合 6-9 次区间 |
| `4101` | 4s 离心 - 1s 底部 - 0s 向心 - 1s 顶部 | 同上，向心瞬间发力（张力时间 + 部分速度） |
| `3111` | 3s 离心 - 1s 底部 - 1s 向心 - 1s 顶部 | 强度上升期的过渡节奏：张力时间略减 |
| `3101` | 3s 离心 - 1s 底部 - 0s 向心 - 1s 顶部 | 同上，向心发力更快 |
| `2010` | 2s 离心 - 0s 底部 - 1s 向心 - 0s 顶部 | 偏力量/爆发节奏，接近常规训练 |
| `1010` | 1s 离心 - 0s 底部 - 1s 向心 - 0s 顶部 | 无节奏控制（常规训练） |
| `X·1·1·1` 系列 | 自定义离心秒数 + 1s 停顿 | 如需更长离心（5s+）可扩展 |

> ⚠️ 表中数值来源：PHUL Advanced 6 天版实际使用 `4111 / 4101 / 3111 / 3101` 四档，随周期强度上升从 4s 离心推进到 3s 离心。`2010 / 1010` 为通用训练学补充码。

### 2.3 如何选节奏码

| 目标 | 建议节奏 | 说明 |
|------|---------|------|
| 肌肥大张力时间最大化（增肌辅助） | 3-4s 离心 + 1s 停顿（`4111`/`4101`/`3111`/`3101`） | 每重复 6-9 秒张力，适合辅助/孤立动作 |
| 力量与爆发（主项 TS/BO） | 1-2s 离心、无停顿（`2010`/`1010`） | 主项追求速度与机械效率，**不建议加慢节奏** |
| 技术练习 / 轻量日 | 2-3s 离心 + 停顿 | 增加动作控制，降低重量安全性 |

## 3. RPS 组间休息

### 3.1 与训练目标对应

| 训练目标 | 建议组间休息 | 说明 |
|---------|-------------|------|
| 最大力量（TS/BO） | 2-5 分钟 | 充分恢复神经募集，保证下一组强度 |
| 肌肥大（复合辅助） | 75-120s | 张力+代谢压力平衡 |
| 肌肥大（孤立辅助） | 45-75s | 小肌群恢复快，紧凑休息累积代谢压力 |
| 肌肉耐力 / 高次数组 | 30-60s | 代谢压力主导 |
| 技术练习 | 60-90s | 保持动作质量 |

> ⚠️ 表中数值来源：PHUL Advanced 6 天版增肌日使用 `75s → 60s`（周期内逐周收紧）与 `120s`（W13 高重低次数组）。其余区间为通用训练学常识。

### 3.2 周期内推进模式（参考 PHUL 6 天版）

| 阶段 | 节奏推进 | 休息推进 |
|------|---------|---------|
| 块前段（1-3 周） | 4s 离心（`4111`） | 75s |
| 块中段（5-7 周） | 4s 离心（`4101`） | 60s |
| 块后段（9-12 周） | 3s 离心（`3111`→`3101`） | 60s |
| 峰值周（W13 高重低次数组） | 4s 离心（`4101`） | 120s（3 次重组的恢复需要） |

逻辑：**强度上升 → 节奏加快、休息收紧**（保持张力密度），**高重低次数组则放宽休息**（保重优先）。

## 4. 与 skill 现有体系叠加

| 现有参数 | 叠加方式 |
|---------|---------|
| **RPE** | 节奏/休息与 RPE 独立。RPE 定重量，TUT/RPS 定动作执行方式。输出示例：`3×8 @ RPE 7，TUT 4111，休息 75s` |
| **双进阶** | 节奏不变、次数先进阶；次数到顶后加重回到底限，**不要**同时加速节奏——节奏码是质控参数，不是进阶参数 |
| **MRV 审计** | 节奏变慢会增加每组疲劳（张力时间延长），审计时可对采用慢节奏（4s 离心）的辅助动作按 1.1-1.2 系数折算等效组数（谨慎，勿过度设计） |
| **周期推进** | 节奏码可随周期阶段推进（容量期慢、力量期正常），与 JTS 的容量期→力量期结构同步 |

### 输出格式示例（辅助动作）

```
**上斜哑铃卧推（辅助）**：4×8 @ RPE 7，TUT 4111，组间休息 75s（双进阶）
```

## 5. 边界与注意事项

| 规则 | 说明 |
|------|------|
| ❌ 主项 TS/BO 不加慢节奏 | 力量主项追求速度与机械效率，慢节奏稀释力量适应性；主项节奏只用于技术练习/轻量日 |
| ❌ 节奏码不做进阶工具 | 节奏是执行规范，不是渐进超负荷手段；进阶仍走双进阶/RPE |
| ❌ 有伤病/关节不适时慎用慢离心 | 4s 离心增加关节张力时间，疼痛管理优先参考 `pain-management.md`（BBM 框架） |
| ⚠️ 慢节奏 ≠ 力竭 | 慢节奏只延长张力时间，仍按 RPE 留次/力竭管理，不因节奏改变力竭策略 |
| ⚠️ 不适用于每个动作 | 优先给增肌日辅助/孤立动作配 TUT/RPS；复合动作给 RPS 即可，节奏可省略 |
| ✅ 6 天模板必读 | 设计 6 天/周计划时，第 6 天（功能/小肌群日）的辅助动作建议配 TUT/RPS（见 `output-templates.md` 模板四） |
